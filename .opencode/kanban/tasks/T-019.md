# Toggle nudge visibility (nudge.visible + nudge.visibleMarker)

Added two config keys controlling how nudges are delivered and marked:

- `nudge.visible` (default `true`): when `false`, the user message is left untouched and the nudge is delivered as a hidden `synthetic` text part via `experimental.chat.messages.transform`. The model sees it, the chat UI does not, and it is never persisted.
- `nudge.visibleMarker` (default `true`): when `false`, the `wrapper.prefix`/`wrapper.suffix` block is suppressed even if those strings are non-empty. The nudge text is still injected.

Both keys are overridable per-prompt. Interval math, `computeDue`, and counter ownership stay identical across visibility modes; delivery for `nudge.visible === false` happens inside the injector's single transform handler via `setPrimaryInvisibleProvider`.
