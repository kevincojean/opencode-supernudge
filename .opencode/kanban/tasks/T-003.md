# Scope nudge frequency per nudge prompt

## Problem
Currently ALL injection settings are global - one interval, one position, one enabled flag per channel applies to every prompt.
User wants per-prompt override capability: each prompt can override any subset of global settings.

## Current config shape
```jsonc
{
  "prompts": ["~/tdd.md", "~/givenwhenthen.md"],
  "injection.interval": 1,
  "injection.alwaysOnFirstMessage": true,
  "injection.resetCounterOnCompaction": true,
  "position.normalMessage": "start",
  "position.subagent": "start",
  "position.compaction": "start",
  "enabled.normalMessage": true,
  "enabled.subagent": true,
  "enabled.compaction": true
}
```

## Proposed config shape
Global keys become DEFAULTS. Each prompt entry can override any subset.

```jsonc
{
  "prompts": [
    "~/tdd.md",
    { "path": "~/givenwhenthen.md", "injection.interval": 3 },
    {
      "path": "~/no-mocking.md",
      "injection.interval": 1,
      "position.normalMessage": "end",
      "enabled.compaction": false
    }
  ],
  // these are now defaults for prompts that don't override them
  "injection.interval": 1,
  "injection.alwaysOnFirstMessage": true,
  "injection.resetCounterOnCompaction": true,
  "position.normalMessage": "start",
  "position.subagent": "start",
  "position.compaction": "start",
  "enabled.normalMessage": true,
  "enabled.subagent": true,
  "enabled.compaction": true
}
```

String entries = shorthand for `{ "path": entry }` (all defaults apply).

## Overridable keys per prompt
Every global key except `prompts` itself:
- `injection.interval`
- `injection.alwaysOnFirstMessage`
- `injection.resetCounterOnCompaction`
- `position.normalMessage`
- `position.subagent`
- `position.compaction`
- `enabled.normalMessage`
- `enabled.subagent`
- `enabled.compaction`

## Acceptance Criteria (GivenWhenThen)

### AC1: Per-prompt interval basic
Given config with two prompts having interval=1 and interval=3, when 3 messages sent, then prompt A injected on all 3, prompt B injected on 1st and 3rd only.

### AC2: Backward compat - string entries
Given config with prompts as string[] and global interval=2, when 3 messages sent, then all prompts inject on 1st and 3rd (global interval applies to all).

### AC3: Mixed string and object entries
Given config with prompts: ["~/a.md", { "path": "~/b.md", "injection.interval": 1 }] and global interval=3, when 3 messages sent, then a.md injects on 1st and 3rd, b.md injects on all 3.

### AC4: Per-prompt alwaysOnFirstMessage override
Given config with { "path": "~/a.md", "injection.interval": 5, "injection.alwaysOnFirstMessage": false } and global alwaysOnFirst=true, when 1st message sent, then a.md NOT injected.

### AC5: Per-prompt interval with compaction reset
Given config with two prompts having different intervals and resetCounterOnCompaction=true, when compaction fires then next message sent, then both prompts inject (counter reset for all).

### AC6: Per-prompt enabled.normalMessage override
Given config with { "path": "~/a.md", "enabled.normalMessage": false } and global enabled.normalMessage=true, when chat.message fires, then a.md NOT injected in user message, other prompts still inject.

### AC7: Per-prompt position.normalMessage override
Given config with { "path": "~/a.md", "position.normalMessage": "end" } and global position.normalMessage=start, when chat.message fires, then a.md appended at end, other prompts at start.

### AC8: Per-prompt enabled.subagent override
Given config with { "path": "~/a.md", "enabled.subagent": false } and global enabled.subagent=true, when system.transform fires, then a.md NOT in system array, other prompts still injected.

### AC9: Per-prompt position.subagent override
Given config with { "path": "~/a.md", "position.subagent": "end" } and global position.subagent=start, when system.transform fires, then a.md at end of system array, others at start.

### AC10: Per-prompt enabled.compaction override
Given config with { "path": "~/a.md", "enabled.compaction": false } and global enabled.compaction=true, when session.compacting fires, then a.md NOT in context array, other prompts still injected.

### AC11: Per-prompt position.compaction override
Given config with { "path": "~/a.md", "position.compaction": "end" } and global position.compaction=start, when session.compacting fires, then a.md at end of context array, others at start.

### AC12: Per-prompt resetCounterOnCompaction override
Given config with { "path": "~/a.md", "injection.resetCounterOnCompaction": false, "injection.interval": 3 } and global resetCounterOnCompaction=true, when 1st message injects then compaction fires then 2nd message sent, then a.md does NOT inject on 2nd message (its counter was NOT reset, still at count=2, next inject at count=3).
