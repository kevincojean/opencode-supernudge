# Periodic nudge injection during autonomous agent/sub-agent work

Inject nudges periodically (every N turns) only while an agent or sub-agent is working autonomously. This is a SEPARATE counter from the existing user-message counter - they must not interfere.

## Acceptance criteria (GivenWhenThen)

- Given an agent is working autonomously, when N turns have elapsed since the last nudge, then the configured nudges are injected into the next autonomous turn.
- Given a user sends a message, when the user-message counter is incremented, then the autonomous counter is NOT affected.
- Given an agent turn occurs, when the autonomous counter is incremented, then the user-message counter is NOT affected.
- Given both counters would fire on the same turn, when that turn happens, then each counter's injection policy is evaluated independently against its own count.

## Out of scope
- Subagent-specific scoping (tracked separately as T-002).
- Skipping by message content substrings (tracked separately as T-011).
